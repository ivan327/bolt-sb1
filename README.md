# Bolt Starter

Стартовый шаблон для bolt.new: Vite + React + TypeScript.

## Запуск

```bash
npm install
npm run dev      # режим разработки на http://localhost:5173
npm run build    # проверка типов и сборка в dist/
npm run preview  # предпросмотр собранной версии
```

## Структура

- `index.html` — точка входа Vite
- `src/main.tsx` — монтирование React
- `src/App.tsx` — главный компонент
- `src/index.css` — стили
- `vite.config.ts`, `tsconfig.json` — конфигурация
